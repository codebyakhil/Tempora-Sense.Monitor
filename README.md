# Images Folder

Add your circuit diagram / breadboard photo / LCD output photo here, for example:

- `circuit_diagram.png` – Fritzing or hand-drawn wiring diagram
- `breadboard_photo.jpg` – Real photo of your assembled circuit
- `lcd_output.jpg` – Photo of the LCD showing a live temperature reading

Reference these images in the main `README.md` using:

```markdown
![Circuit Diagram](images/circuit_diagram.png)
```
